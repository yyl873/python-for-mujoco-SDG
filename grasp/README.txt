================================================================================
 grasp/  —— 步骤二：纯物理接触与抓取（核心）
================================================================================
【这个目录是干什么的】
    验证"药盒能被真实接触力抓住"，全程零 qpos 覆盖。
    这是整个项目最关键的一步：证明不靠视觉欺骗也能抓起来。

【文件】

    test_grasp.py  ★ 主文件（365 行）
        纯物理抓取 + 搬运完整闭环。

        结构：
            class Arm                    模型的索引与基本操作封装
                .ik(target, seed)        DLS 逆运动学（会保存/恢复 qpos，不污染物理状态）
                .move(q_target, gctrl, n_steps)
                                         关节空间线性插值移动，同时统计碰撞
                .grip_contacts()         读 mj_contactForce，分 jaw / grip 两侧
                .arm_hits()              药盒与机械臂的接触（排除支撑面）
                .tbox_contacts()         药盒与木盒的接触（约束2 的检查项）

        七个阶段：
            0  自然落定 1200 步
            1  IK 求三个路点：高位撤回 z=0.24 / 正上方 z=0.16 / 抓取点 z=0.046
            2  home -> 高位撤回 -> 正上方（夹爪全开 1.70）
            3  竖直下探（约束1：途中不能碰倒药盒）
            4  合爪 ctrl 1.70 -> 0.00 线性 300 步  ← 真实接触力在这里产生
            5  竖直抬升
            6  水平搬运到木盒上方（约束2：不能碰木盒）

    test_physics.py
        步骤二的早期探索版（约 400 行），保留作参考。
        内容是对"物块为什么弹飞/滑落"的接触力分析，比 test_grasp.py 啰嗦，
        里面有一些已被 test_grasp.py 吸收的实验代码。日常用 test_grasp.py。

【怎么运行】
    cd /home/yyl/deepseek-harness
    env -u PYTHONHOME -u PYTHONPATH python3 grasp/test_grasp.py
    env -u PYTHONHOME -u PYTHONPATH python3 grasp/test_grasp.py --no-transport
    env -u PYTHONHOME -u PYTHONPATH python3 grasp/test_grasp.py --roll 105 --gz 0.030

    参数：--roll 腕部滚转(度, 默认120)  --gz 抓取TCP高度(m, 默认0.046)
          --no-transport 只抓不搬   --settle 落定步数(默认1200)

【预期输出（实测基准，改任何参数都要和这组数对比）】
    合爪接触     6 个（jaw 2 + grip 4）
    合爪法向力   34.70 N   （药盒重力仅 0.1128 N，摩擦裕度 6151 倍）
    抬升         +92.55 mm
    握持接触     8 个（jaw 4 + grip 4）
    水平搬运     155.1 mm，到达木盒位置 [0.4499 0.0987 0.1359]
    木盒碰撞     0 / 600 步

【关键物理事实（不是调出来的，是几何决定的）】
    * gripper_joint 语义：1.70 = 张开最大，0.00 = 闭合
    * wrist_roll 限位 ±2.3 rad = ±131.8°，135°/180° 都会被 clip 到 131.8°
    * 夹口张开方向在世界系里不天然对准药盒 15mm 厚度向(y)，必须靠腕部滚转到 120° 掰正
    * 搬运方向必须垂直于夹持轴：药盒只有 15mm 厚可夹，沿该轴搬运必然把它挤出去
      （实测沿 y 搬运第 334 步掉落，沿 x 才全程不掉）
    * home 姿态的 ctrl 默认为 0，落定后手臂塌到 q≈0，TCP 在 (0.39,0,0.22)，
      所以必须先"高位撤回"再平移，否则会横穿药盒把它扫倒
