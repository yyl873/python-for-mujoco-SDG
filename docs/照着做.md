# 二、科目① MuJoCo 本体（D1–D2，10-31 ~ 11-01）

## 第 1 步：数一下你的模型有多少自由度（10 分钟）

**干什么**：把 XML 里到底有什么搞清楚，这是面试第一问。

**敲**：
```bash
cd /home/yyl/deepseek-harness
env -u PYTHONHOME -u PYTHONPATH /usr/bin/python3 - <<'EOF'
import mujoco
m = mujoco.MjModel.from_xml_path("model/so_arm101.xml")
d = mujoco.MjData(m)
print("nq =", m.nq, " nv =", m.nv, " nu =", m.nu)
print("timestep =", m.opt.timestep, " integrator =", m.opt.integrator,
      "(0=Euler 1=RK4 2=implicit 3=implicitfast)")
print("cone =", m.opt.cone, " impratio =", m.opt.impratio)
for i in range(m.nu):
    print(f"actuator {i}: trntype={m.actuator_trntype[i]} "
          f"gainprm={m.actuator_gainprm[i][:3]} "
          f"forcerange={m.actuator_forcerange[i]}")
EOF
```

**看到什么算过**（这是实测输出，你打出来应该一模一样）：

```text
nq = 6  nv = 6  nu = 6
timestep = 0.002  integrator = 0 (0=Euler 1=RK4 2=implicit 3=implicitfast)
cone = 1  impratio = 10.0
actuator 0: trntype=0 gainprm=[150.   0.   0.] forcerange=[-3.35  3.35]
...（6 行 actuator，全一样）
```

**这几个数的意思**（面试就这么答）：
- `nq = nv = 6`：6 个 hinge 关节，每个关节 1 个位置 + 1 个速度 → 相等。
  **如果哪天有 free joint，就会变成 nq=7 / nv=6**，这是必考的点。
- `nu = 6`：6 个 position actuator，`ctrl` 就是**目标关节角（弧度）**，不是力矩。
- `trntype = 0`：`mjTRN_JOINT`，说明执行器作用在关节上（不是 tendon/site）。
- `gainprm[0] = 150`：就是 XML 里的 `kp=150`。PD 里的 `kv=10` 在 `biasprm` 里（`biasprm[2] = −kv`）。
- `forcerange = ±3.35`：STS3215 堵转扭矩上限，仿真不许超过真机能力。
- `timestep = 0.002`：`7500 步 × 0.002 = 15 秒`，这是你渲染时长的来历。
- `integrator = 0`：默认 Euler。
- `cone = 1`：椭圆摩擦锥（0 = 多面体金字塔锥）。

## 第 2 步：查 XML 的每个字段（40 分钟）

**干什么**：把 `model/so_arm101.xml` 打开，**每一个你没把握的属性都去官方文档查一遍**。

```text

<position kp="150" kv="10" forcerange="..."/>  ← PD 控制 / 力矩上限

condim="4"                                     ← 接触维度
```

**文档地址**：`https://mujoco.readthedocs.io` → **XML Reference** 章节。

而且能说出 `forcerange=-3.35` 是从哪来的（STS3215 堵转扭矩）。

# 五、科目④ 统计检验（D6，11-05）

## 第 12 步：手算一遍你的 Fisher 检验（30 分钟）★

**干什么**：不调库，把 1/12 vs 9/12 的 p 值自己算出来。**手算过一次，这辈子忘不了。**

**敲**：
```bash
cd /home/yyl/deepseek-harness
env -u PYTHONHOME -u PYTHONPATH /usr/bin/python3 - <<'EOF'
from scipy.stats import fisher_exact
import numpy as np

# 2x2 表：行=A/B，列=抓取成功/失败
for name, tab in [
    ("A@22500   vs B@22500",   [[1, 11], [8, 4]]),
    ("A@22500   vs B_ft_real", [[1, 11], [9, 3]]),
]:
    _, p = fisher_exact(tab)
    print(f"{name}   Fisher p = {p:.4f}")

def wilson(k, n, z=1.96):
    p = k / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * np.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return c - h, c + h

for name, k, n in [("A@22500", 1, 12), ("B@22500", 8, 12), ("B_ft_real", 9, 12)]:
    lo, hi = wilson(k, n)
    print(f"{name:<10} {k}/{n} = {k/n:5.1%}   Wilson 95% CI [{lo:.1%}, {hi:.1%}]")
EOF
```

**看到什么算过**（实测输出）：

```text
B@22500    8/12 = 66.7%   Wilson 95% CI [39.1%, 86.2%]
B_ft_real  9/12 = 75.0%   Wilson 95% CI [46.8%, 91.1%]
```
