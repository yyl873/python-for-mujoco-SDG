## 3. 不许动的数字（动了会静默毁掉抓取）

| 项 | 值 | 为什么 |
|---|---|---|
| 接触段步数 | `descend 400 / grasp 300 / lift 400` | 把下探放慢到 1150 步：结构件在盒顶压得更久，药盒被推倒（z 0.0278→0.0041），抓取全废 |
| 总步数 | 7500 步 = 15.0 s = 455 帧 | 与真机平均 448 帧对齐 |
| 合爪量 | **0.28**（rad，`set_gripper` 直传） | 指面间距 ≈7.6 mm/0.1 rad：0.15→4.45 mm（已合拢，会把盒挤出去）、0.28→14.15 mm≈盒厚 15 mm |
| 抓取偏置 | `GRASP_XY_OFFSET dy = +17.5 mm` | 不加时固定指实体整块压在盒里（9814 顶点 / 深 7.5 mm） |
| `wrist_roll` | −90°（抖动幅度设为 0） | 只有 −90° 干净：−95° 下探 6/400 步接触、−100° 压盒 1.58 mm、−105/−110° 抓不起来 |
| `gz` 窗口 | 0.008~0.016（标称 0.012） | 0.020 起指垫在下探段会擦到盒顶 |
| 夹爪张开量 | 0.6~2.232 等价 | 指垫在指内侧，开口不参与接触 |
| 渲染尺寸 | 全程恒定 | 变了 `VideoWriter` 会静默丢帧 |
| PD 增益 | 不要靠加大 `kp` 消稳态误差 | `kp=600` 会冲过头 −29.5 mm 扎进桌子；正确做法是在 IK 目标里预加补偿 |

## 4. 指垫（最容易被改坏的东西）

- 两片：`pad_gripper_link` / `pad_jaw_link`，`50×2×40 mm`，`rgba 0 0 0 0`（**完全不可见**），
  `contype=4 conaffinity=2`、`condim=4`、`friction 1.2 0.01 0.0001`、`solref 0.02 1`、`solimp 0.9 0.95 0.001`。
- 位置不是"贴在药盒表面"，而是**贴合该手指真实内表面**：用**干净参考位姿**（先把指垫碰撞临时关掉跑一遍）
  按药盒足迹窗口（x±37 / z±26 mm）取该指最内侧极点反算。
  贴错的表现：**下探零接触、但抬升 0**（只夹到盒顶）。
- 局部 `pos/quat` 与「起止姿态 + 接近路径（init_lift / approach_retract / approach_above）+ 步数配比」**耦合**：
  改任一项都要用 `debug/pad_flush_try.py --emit-mjcf` 重算这两组数。
- 指壳体网格设成 `contype=8 conaffinity=1`（只和一般几何碰，不再和药盒碰），否则凸包会戳盒子。

## 6. 已知的、不是 bug 的现象

| 现象 | 原因 | 能不能修 |
|---|---|---|
| 搬运途中药盒歪 **27~30°** | 本臂 lift/elbow/flex 三轴平行，工具俯仰随 TCP 高度线性变化 **0.22°/mm**（0.012 m→44.1°，0.16 m→76.3°） | 压不下来（`ik_lock` 试过：位置收敛、指向残差 31.9°）。要么降搬运高度，要么换 6 轴 |
| 起止姿态在竖直方向"折叠" | 起止姿态 = 真机 `initial_pose`（pan 0 / lift −100 / elbow 88.26 / wrist_flex 70.63 / wrist_roll −103.53°，爪甲收起） | 这是刻意的：与真机遥操第一帧一致 |
| 视频 30 fps，物理 29.41 fps | 时间栅格录帧 + decimate 取整 | 播放快 2%，肉眼不可见 |
| 夹爪量程与真机不同 | 仿真 0~86°（全开 2.232 rad≈128°）；真机数据集 1.2~42.3° | 字段名/单位/维数已对齐，**量程差要在部署侧确认映射** |
| `grasp/test_grasp.py` 抓空（抬升 4.51 mm） | 它的动作序列与生产路径分叉（缺 settle_a、下探段压盒 21.85 mm） | 已退出流水线，**别拿它当判据** |

## 7. 环境与随机化

- 版本：Python 3.10.12 / mujoco 3.16.0 / numpy 1.21.5 / opencv 4.5.4；渲染只认 `MUJOCO_GL=egl`。
- `mj_step` 偶发 SIGFPE（约 7%）：进程直接消失，重跑即可；已完成的不受影响（每条一个原子写的索引片段）。
- 随机化六个维度（都写进每条 json，可复现）：场景旋转 ±10°、药盒出生位姿、抓取参数小幅抖动、
  节奏 ×0.90~1.10（只动自由段与停顿段）、环境相机 ±1~3 cm / fovy±3° / yaw±2° / pitch±2°、传感器劣化 + 视觉随机化。
  相机名义位姿在 `model/so_arm101.xml` 的 `env_camera`（= 真机 `_fixed` 批次视角），
  抖动基准由 `apply_camera_jitter` 从模型现读 —— **不要再在代码里写死相机位姿**。
  实测（12 个 seed）：抖动后垫子仍 100% 贴下边框、0% 整块进画面，左缘 336~423 / 上缘 260~303 / 宽 217~284，与真机 370~420 / 284~291 / 205~270 同量级。
- 每条随机种子 = `SeedSequence([base_seed, episode_id])` → **`--n 1000` 与「跑 500 + 续 500」逐位相同**。
- 药盒全程必须留在绿垫上（垫半径 96 mm、footprint 半对角 37.8 mm → 盒心偏移上限 56.2 mm）。
