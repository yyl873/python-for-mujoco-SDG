## 0. 一句话

用户看视频后指出：「下落抓取必然撞倒或戳到药盒，产生回弹，但现实没有这个机制」——**这句话是对的，且能量化**。
根因不是参数，是**指尖碰撞几何**：C 形指壳被 MuJoCo 当凸包用，凸包把 C 的开口填满，"两指之间"在碰撞里是实心的。

|---|---|---|
| 下探段 指尖↔药盒 接触步数 | **92 / 400** | **0 / 400** |
| 下探段峰值法向力 | **2.73 N**（自重 0.113 N 的 24 倍） | 0 |
| 药盒底面最低点 | **−5.10 mm**（沉到桌面以下） | **+1.55 mm** |

| 抬升 / 水平 | +103.45 / 221.01 mm | **+125.10 / 209.56 mm** |

## 2. 实测：把观感变成数字（`tools/probe_contact_audit.py`，逐仿真步，0.5 s/条）

修前（oldros 起点、sdg-v3 步数、gz=0.012）：

```
descend 段 400 步里 92 步有"指尖↔药盒"接触
首次接触：step 3710，TCP z = 58.72 mm（盒顶 53.77）—— 指尖还没到盒腰就先落在盒顶
          接触点 (305.4, 94.2, 53.7) mm，法向 (0,0,+1)：正压在盒顶面
峰值 Fn 2.73 N，接触 dist = −13.19 mm（求解器穿透）
下探末：药盒中心 27.77 -> 20.90 mm，底面 −5.10 mm（桌面 z=0、垫面 +2.00）
之后回弹到 23.47 mm（+2.56 mm）
倾角：descend 末 3.47° -> grasp 末 9.91° -> settle_a 末 10.95° -> lift 峰 29.12° -> transport 30.94°
接触法向 z 分量均值 +0.402：载荷是"往下压"，不是"两侧夹"
接触件：g26 / g28（指壳的碰撞 mesh），不是指垫
```

**结论：修前那 103 mm 的"成功"，是靠指尖压在盒顶把盒子掐住撑起来的。** 这与 `HANDOFF` §6.2-3 早先记的
「约束1 ❌ Δz −6.85 mm、压盒 6.3、回弹 1.7、gz≥0.020 抬升只剩 4.5 mm」是同一件事，只是这次有了帧级证据。

## 3. 根因：凸包把 C 形件的开口填满了

用 MuJoCo 自己的距离函数（`mj_geomDistance`，凸包 vs 盒）沿下探路径逐点量：

| 下探进度 | 固定指到药盒的最小距离 |
|---|---|
| TCP 160 mm | +100.9 mm |
| TCP 124.7 | +66.1 mm |
| TCP 87.7 | +29.0 mm |
| TCP 49.8 | **−9.08 mm** |
| TCP 12.0 | **−22.57 mm** |

也就是说**完全下探位姿下，固定指的碰撞体穿进药盒 22.6 mm**。再把药盒沿 y 平移：

| 药盒 y 平移 | 固定指最小距离 | 活动指最小距离 |
|---|---|---|
| 0 mm | −22.6 | +27.3 |
| +15 mm | −7.9 | +41.4 |
| +30 mm | +6.8 | +55.8 |

要"不穿模"得把药盒推 30 mm，那时活动指已经离盒 55 mm —— **两个指头根本没法同时落在药盒两侧**。
三条旁证：

- 张开量 **1.5 与 2.232 的下探接触步数完全一样（92/92）** —— 不是"张不够"；
- 抬高 gz 只把压盒量线性降下去（0.012→6.87 mm、0.016→6.48、0.020→5.96、0.036→3.48），**永远压不平**；
- 抬到 gz≥0.020 抓取就废了（抬升 4.5 mm）—— 说明"抓得住"完全依赖那次戳压。

## 4. 修法：两片平面指垫 + 碰撞位掩码

### 4.1 位掩码（`model/scene.xml` + `model/so_arm101.xml`）

位定义：bit0(1)=通用件（臂/桌/垫/木盒/地面）；bit1(2)=药盒；bit2(4)=指垫；bit3(8)=指壳。
判定规则：`(contype1 & conaffinity2) || (contype2 & conaffinity1)`。

| 对象 | (contype, conaffinity) | 效果 |
|---|---|---|
| 药盒 `object_physics` | (2, 5) | 与通用件、指垫碰；与指壳不碰 |
| 指壳碰撞 mesh（gripper_link 的 2 个 + jaw_link 的 1 个） | (8, 1) | 与通用件碰（桌子/木盒）；与药盒不碰 |
| 指垫 `pad_gripper_link` / `pad_jaw_link` | (4, 2) | **只与药盒碰** |

⚠️ 指垫一开始写成 (4, 3)（也碰通用件），结果 20 条里有 2 条报 `arm_hit_box` —— 指垫新增的碰撞体
在放件/退出木盒时蹭到木盒。改成 (4, 2) 后 20/20。

### 4.2 指垫几何与位置（最重要的一段，踩过两次）

- 尺寸 **34 × 2 × 34 mm** 的 box，`condim=4`、`friction="1.2 0.01 0.0001"`、`solref="0.02 1"`、`solimp="0.9 0.95 0.001"`。
- **两侧算法别搞混**：固定指是**背板**，内侧面留在盒面外侧 **0.2 mm**（否则下探时它先撞盒顶）；
  活动指是**压头**，闭合位（`GRIP_SHUT=0.20`）必须**过压进盒面 0.4 mm**（否则合到底也夹不到 —— 实测两版就差这 1.6 mm，第一版下探零接触、抬升 0.00 mm）。
- **局部坐标按"真实到达位姿"算，不是按 IK 目标算**：`descend` 段末实际停在 TCP=**23.57 mm**，
  而 IK 目标是 12 mm（PD 稳态误差 11.6 mm）。按 IK 目标贴垫 → 垫子高 23 mm、只夹到盒顶 20 mm
  → 合爪阶段 0 接触、settle_a 只有 0.15 N、抬起后歪 27°。
  正确做法是**两趟**：先只关指壳碰撞跑一遍 → 取 descend 段末真实关节位姿 → 再按这个位姿贴垫。
  两趟的做法留在 `debug/pad_fit_try.py`（`capture_reached_pose()` + `build_padded_spec()`）。
- 写进 MJCF 的数值（body 局部系，已固化）：

```
gripper_link: pos="-0.016326 0.003141 -0.095082" quat="0.741404 -0.318476 0.231482 0.543423"
jaw_link    : pos="-0.021867 -0.067551 0.019129" quat="0.301245 -0.743932 0.555408 0.217574"
```
  这两组数依赖「起止姿态 + 接近路径 + 步数配比」。**任一项变了都必须重算**（跑 `debug/pad_fit_try.py` 取新值）。

## 5. 参数敏感度（修后实测，`tools/probe_contact_audit.py`）

| 扫什么 | 结果 |
|---|---|
| `timing_scale` 0.90~1.10（11 档） | **11/11 全过**（下探恒 0 接触、压盒 0.22、抬升 125.03~125.16） |
| `gz` 0.008 / 0.010 / 0.012 / 0.014 / 0.016 | 全过；`0.020` 出现 1 步接触（垫子开始在下探段擦到盒顶）→ 保持 **0.012** |
| `grip`（下探张开量）0.6 / 1.0 / 1.5 / 2.0 / 2.232 | **完全等价**（数字逐位相同）—— 指垫在指内侧，张开量不再影响接触 |
| `roll` | **只能 −90°**：−95°→下探 6/400、夹稳倾 2.52°；−100°→9/400、压盒 1.58 mm；−105/−110°→压盒 26~28 mm、抓不起来 |

★ 由此得两条新规矩：

1. **时序临界性消失了**：sdg-v2 时代 golden 起点在 5 档节奏里挂 3 档，现在 11 档全过 —— 因为下探段根本不接触，"进入 descend 时的残留速度"不再决定成败。
2. **roll 从"可抖动自由度"变成"指垫对齐轴"** → `collect/collect.py` 的 `ROLL_JITTER_DEG` 从 ±4° 改成 **0**，
   并把候选表里 |Δroll| > 0 的候选一并过滤（否则每条要多试 5~7 次、而且那些候选必然违反 G1）。

## 6. 未解决：搬运途中倾角 27°（运动学固有，不是接触伪影）

修后 `lift`/`transport` 段药盒仍会歪到 **27~30°**。查证结论：

- 本臂 `shoulder_lift / elbow_flex / wrist_flex` **三轴平行**，工具俯仰由三者之和决定；
- 实测**俯仰随 TCP 高度线性变化 0.22°/mm**：0.012 m → 44.1°，0.16 m → 76.3°（+32.2°）；
- 所以"从正上方捏住薄盒再竖直抬 100 mm"必然让手腕俯仰 ~22°，握在手里的盒子跟着转；
- 试过 `Arm.ik_lock()`（位置硬约束 + 指向软约束 + 零空间拉回种子）→ **压不下来**：
  位置收敛到 0.06 mm，但指向残差 **31.87° 且与权重无关**（0.02/0.05/0.1/0.2 全一样），
  说明"该高度 + 固定指向"在这条链上不可同时满足。方法保留在 `grasp/test_grasp.py` 里，注释写明负结果。
- 真要减小只有两条路：**降低搬运高度**（抬升量随之变小，且要重新验证放件）或**换 6 轴**。

因此 `tools/probe_contact_audit.py` 的 G3 判据是「**夹稳那一刻**（settle_a 末）倾角 ≤5°」，
搬运途中倾角单列 `carry_tilt_max_deg` **只报不判**。
