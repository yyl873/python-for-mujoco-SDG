================================================================================
 ik/  —— 步骤一：纯 MuJoCo 阻尼最小二乘（DLS）逆运动学
================================================================================

【这个目录是干什么的】
    在没有 MoveIt 的情况下，用 MuJoCo 的雅可比矩阵自己算逆运动学：
    给定末端目标坐标 (x, y, z)，解出 5 个手臂关节角。

    这是纯运动学求解，不涉及物理、不涉及抓取。目的是给 grasp/ 提供路点姿态。

【文件】
    test_ik.py
        唯一文件。176 行，零外部依赖（只要 mujoco + numpy）。

        核心函数：
            solve_ik_to_xyz()    DLS 迭代求解
                dq = Jᵀ (J·Jᵀ + λ²I)⁻¹ · err
                λ=0.05，单步关节增量上限 0.2 rad，limit 裁剪
            load_model()         按名字查 qpos 地址，不硬编码下标

        文件内含中文注释，解释三件事：
            1. 雅可比矩阵 J 如何把"关节速度"翻译成"末端速度"
            2. 阻尼系数 λ 如何在奇异位形下把增益从 1/σ 压成 σ/(σ²+λ²)，防止关节抽搐
            3. 为什么要迭代（一阶泰勒只对局部成立）

【怎么运行】
    cd /home/yyl/deepseek-harness
    env -u PYTHONHOME -u PYTHONPATH python3 ik/test_ik.py
    env -u PYTHONHOME -u PYTHONPATH python3 ik/test_ik.py 0.25 -0.05 0.10   # 自定义目标

【注意事项】
    * IK 是纯运动学解，不含重力。物理执行时肘部有约 0.075 rad 的 PD 稳态误差，
      导致实际末端偏低 10~16 mm。要提高 kp 来消除是错的（kp=600 会扎进桌面），
      正确做法是在 IK 目标里预加补偿。详见 docs/HANDOFF.md 第 4 节。
    * 路径用 __file__ 锚定到仓库根，从任何目录运行都能找到 mjcf/scene.xml。
