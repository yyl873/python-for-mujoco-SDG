【这个目录是干什么的】
    项目最开始走的是 ROS 2 + MoveIt 路线，这份代码是那时候的产物。
    现在已经彻底废弃这条路线，原因是：

      1. MoveIt 做 IK 需要起一堆节点，调试一次几分钟，而纯 MuJoCo 只要 0.2 秒
      2. MoveIt 的运动规划假设刚体+理想夹爪，和纯物理抓取的失败模式对不上
      3. ROS 的 launch 文件把"模型、控制、可视化"绑在一起，没法单独调物理参数
      4. 目标是 SDG 数据合成，需要成千上万次 episode，ROS 的启动开销完全不可接受

    所以本目录只保留作"运动学思路"的参考，不参与当前流水线。

【文件清单】

  send_trajectory.py    25.8 KB
        旧的 ROS 版轨迹下发脚本。里面含 DLS 逆运动学求解（solve_ik_to_xyz）
        和 ROS 2 通信（rclpy / MoveIt / trajectory_msgs）。

        现在唯一还有价值的部分：solve_ik_to_xyz 的求解思路。
        但这段精华已经被重写进 ik/test_ik.py（更干净、带中文原理注释、
        不依赖任何 ROS 包），所以实际上不需要再打开这个文件了。

【重要警告】
    * 里面 import rclpy / moveit / launch —— 本机没有装 ROS，直接跑会 ModuleNotFoundError。
    * 不要把这里的代码复制回 step1~step3。当前三条红线之一就是"零 ROS"。
    * 如果只是想看 IK 怎么解，去看 ik/test_ik.py。
    * 如果想知道为什么放弃 ROS，看 docs/HANDOFF.md。
